공공데이터 정밀데이터지도 기반 데이터 거버넌스 지식 탐사

공공데이터포털 1,000개 테이블의 정밀데이터지도 데이터를 분석하여 컬럼 도메인/값 정합성, 도메인/값 연관성, 대표 도메인, 테이블 연계, PK/FK 후보, 업무규칙 후보를 도출합니다.

1. 분석 파일 선택

프로젝트 목적
이 분석기는 정밀데이터지도 데이터를 대상으로 데이터 거버넌스 지식을 탐사합니다. 결과는 표준 도메인 사전 후보, 컬럼 표준화 후보, 값 정합성 규칙 후보, 테이블 연계 후보, 마스터 테이블 후보, 업무규칙 후보로 정리됩니다.

대용량 안전 설정

대용량 파일은 앞·중간·뒤 구간을 각각 지정 MB만큼 층화 샘플링합니다. 기본 80MB이면 파일당 최대 240MB를 분석합니다.
