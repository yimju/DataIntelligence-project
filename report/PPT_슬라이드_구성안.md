## 공통 정렬 규칙 (전 슬라이드 고정)
- **그리드(높이 7.5")**: 제목영역 0.40–1.14" · accent rule 1.16" · 핵심메시지 1.28–1.84" · 본문/시각 2.00–6.95" · 푸터 7.04"
- **좌우 여백**: 0.62" 동일. 본문 bullet·표·도식 모두 좌측 기준선 0.62"에 정렬
- **제목**: 좌측 상단 고정, 26pt Bold, **Deep Navy(8,31,70)**, 마침표 없음, 최대 2줄
- **핵심메시지**: 제목 아래 1문장, 15pt Bold, 거버넌스=Dark Gray(80,80,80) / 인텔리전스=Accent Green(0,150,95)
- **본문 bullet**: 15pt, `•` 동일 기준선, 3~5개, 줄간격 1.04 고정, 하위 1단계만
- **카드**: 헤더 0.40" 색띠(Navy/Green) + 본문, 크기·간격 동일. 강조색은 처리/의미=Navy, 대책/추가분석=Green 규칙 적용
- **표**: 헤더행 Navy/White, 짝수행 연한 네이비 음영, 좌측열 좌정렬·수치열 중앙
- **캡션**: 시각자료 하단 9.5pt Dark Gray · **페이지번호**: 우측 하단 10pt Gray(120,120,120)

## 슬라이드별 구성

### Slide 1. 표지
- 레이아웃: 풀블리드 Navy 배경 + 중앙 좌측 제목블록, 하단 그린 라인
- 제목 위치: 수직 중앙(2.5"~), 34pt White
- 핵심 메시지: 부제 2줄(White / Green)
- 시각 자료: 없음(색면 구성)
- 강조 색상: 배경 Deep Navy, 강조 Accent Green
- 정렬 기준: 좌측 여백 0.62" 동일

### Slide 2. 분석 개요 및 목적
- 레이아웃: 좌측 bullet 55% + 우측 카드 2개 45%
- 제목 위치: 좌측 상단 고정
- 핵심 메시지: 제목 아래 1문장(Dark Gray)
- 본문 bullet: 좌측 5개(대상/구성/목표/형식/원칙)
- 시각 자료: 우측 카드 — ‘5원칙’(Green), ‘도메인 분포’(Navy)
- 강조 색상: 과제지침=Green, 사실데이터=Navy
- 정렬 기준: bullet·카드 상단 동일선(2.00")

### Slide 3. 대상 데이터 구성
- 레이아웃: 상단 핵심메시지 + 중앙 표(9행)
- 제목 위치: 좌측 상단 고정
- 핵심 메시지: 3계층 구조 요약(Dark Gray)
- 시각 자료: 파일×역할×규모 표(열폭 2.2/4.2/1.6)
- 캡션: 출처·집계 스크립트 표기
- 강조 색상: 표 헤더 Navy
- 정렬 기준: 표 좌측 시작점 = 본문 기준선

### Slide 4. 분석 방법론 파이프라인
- 레이아웃: 중앙 5단계 셰브론 도식 + 하단 알고리즘 매핑 표
- 제목 위치: 좌측 상단 고정
- 핵심 메시지: 5단계 한 줄 요약(Dark Gray)
- 시각 자료: 펜타곤 플로우(Navy/Green 교차) + 표(단계/알고리즘/적용)
- 캡션: 재현 스크립트·상세 문서
- 강조 색상: 단계 도식 Navy↔Green 규칙적 교차
- 정렬 기준: 도식·표 폭 = 본문 폭 전체

### Slide 5–8. 공통 데이터 준비 ①~④
> 같은 성격 = 동일 레이아웃(좌측 bullet 중심), 섹션 태그 ‘공통 전처리’(Green)
- **S5 적재·인코딩·형변환**: bullet 5개(인코딩 확정/UTF-8 출력/적재/형변환/정합)
- **S6 1D 이산화**: 좌측 bullet 3개 + 하단 이산화 경계 표 — 강조: log1p·KMeans
- **S7 AOI 롤업**: 좌측 bullet(하위 예시 1단계) + 우측 ‘기관유형 분포’ 카드(Green)
- **S8 트랜잭션·패턴·검증**: bullet 5개(거래/속성/장바구니/채굴/검증)
- 제목 위치: 좌측 상단 고정 / 핵심 메시지: Dark Gray
- 정렬 기준: bullet 기준선·표 시작점 동일(0.62")

### Slide 9. 분석 결과 종합
- 레이아웃: 카드형 4개 가로 등간격
- 제목 위치: 좌측 상단 고정
- 핵심 메시지: 거버넌스 3 + 인텔리전스 4 도출(Green)
- 시각 자료: 카드 4(거버넌스 G1 / G2·G3 = Navy, 인텔리전스 = Green)
- 강조 색상: 거버넌스 Navy / 인텔리전스 Green 규칙
- 정렬 기준: 카드 크기·높이·간격 동일

### Slide 10–13, 15–16. 이슈 슬라이드 (2×2 카드)
> 동일 레이아웃 — 4분면 카드: ①이슈별 데이터 처리(Navy) ②의미 분석(Navy) ③대책(Green) ④추가 필요 분석(Green)
- 제목 위치: 좌측 상단 고정 / 섹션 태그(거버넌스/인텔리전스/검증)
- 핵심 메시지: 이슈 한 줄 요약(거버넌스=Gray, 인텔리전스=Green)
- 시각 자료: 2×2 카드(상단 처리·의미 = Navy, 하단 대책·추가분석 = Green)
- 강조 색상: 처리/의미 Navy, 대책/추가분석 Green (전 이슈 동일 규칙)
- 정렬 기준: 4카드 크기·간격 동일, 카드 내 bullet 3개
- 해당 슬라이드: **S10 G1 출처 결손 / S11 G2 죽은 메트릭 / S12 G3 컬럼 표준·품질 / S13 스키마 패밀리 / S15 교차도메인 재식별 위험 / S16 규칙#4 검증**

### Slide 14. 인텔리전스 흥미로운 연관규칙
- 레이아웃: 좌측 규칙 표(53%) + 우측 카드 2개(‘읽는 법’/‘대책·추가분석’)
- 제목 위치: 좌측 상단 고정
- 핵심 메시지: ‘주말>기저귀>맥주’ 대응(Green)
- 시각 자료: 규칙 표(주제/규칙/conf/lift) + 카드(Navy·Green)
- 캡션: 전체검증·추적성·출처 문서
- 강조 색상: 표 헤더 Navy, 해설 카드 Navy, 실행 카드 Green
- 정렬 기준: 표·카드 상단 동일선

### Slide 17. 종합 시사점 및 거버넌스 대책 로드맵
