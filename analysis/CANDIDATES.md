# 인텔리전스 / 거버넌스 이슈 후보 (1차)

대상: 공공데이터포털 999개 데이터셋(교육 400 / 보건 300 / 공공행정 299)의 **데이터 지도**.
모든 수치는 비지도/집계 알고리즘 실행 결과이며 스크립트(`scripts/`)로 재현 가능. 국소 규칙은 추후 전체검증(규칙#4).

---
## A. 데이터 거버넌스 이슈 후보

### G1. "죽은 메트릭" — 데이터 지도 자체의 미충전 지표
- `null_ratio` = **100% 0** (9,840개 컬럼 전부), `table_qty_index` = 100% 0, `cum_search_num` = 100% 0.
- 카탈로그가 품질/활용 지표를 계산하지 않았거나 적재 실패 → 거버넌스 신뢰성 이슈.

### G2. 출처(provenance) 결손
- `table_source` = 문자 그대로 **"소스"(placeholder)** 인 데이터셋 145개(14.5%). 실제 기관명 미기재.

### G3. 컬럼명 표준 부재 (동일 개념·다른 이름)
- 날짜기준: `데이터기준일자`(169) vs `데이터기준일`(46) vs `등록일`(35)
- 일련번호: `연번`(168) vs `순번`(79) vs `번호`(34)
- 연도: `연도`(62) vs `년도`(26)
- → 마스터 컬럼 사전 부재. 1D/문자 클러스터링으로 표준어 그룹핑 가능.

### G4. 상수 컬럼 / 키 품질
- `distinct_cnt = 1`(상수, 정보량 0) 컬럼 **1,372개(13.9%)**.
- `pk_ratio = distinct/rec` 해석: 거의 유일(>=0.99) 2,256개 / 완전중복(=0… 사실상 상수) 1,145개.

### G5. 스키마 정합성
- `column_cnt ≠ categorical_cnt + numerical_cnt` 인 테이블 **56개** (컬럼 회계 불일치).

### G6. 네이밍-시맨틱 오류 (메타데이터 품질)
- `same_ratio` 는 비율이 아니라 **평균 중복도(rec_cnt/distinct_cnt)** (예: distinct 8, rec 129,168 → 16,146). 컬럼명 오해 소지.

### G7. 도메인 교차 식별자/PII 잠재 (양면: 연계기회 ↔ 프라이버시)
- 전 도메인 공통 컬럼: `전화번호`(140개 테이블), `주소`(85), `위도`/`경도`(44), `성별`, `기관명` 등.
- 보건+교육+공공행정에 같은 값이 함께 존재 → 데이터 연계(인텔리전스) 동시에 재식별 위험(거버넌스).

## B. 비즈니스 인텔리전스("주말>기저귀>맥주" 대응물) 후보

> 이 데이터에는 원본 트랜잭션 행이 없고 **컬럼/테이블 프로파일 + 쌍별 중첩 + 클러스터**가 있음.
> 따라서 "흥미로운 규칙"은 **메타 수준**(어떤 조건의 데이터셋/컬럼이 무엇과 함께 나타나는가)에서 도출.

### I1. 속성 연관규칙 — "어떤 데이터셋 특성이 어떤 품질/구조를 동반하는가"
- 트랜잭션=테이블, 아이템=이산화된 속성(cate1/cate2, rec_cnt-bin, column_cnt-bin, categorical비율-bin 등).
- 1D 이산화 결과 사용(예: rec_cnt 5구간, column_cnt 4구간, pk_ratio 4구간 이미 산출).
- 기대 규칙 예: `{보건의료, 컬럼소수}→{고중복도}`, `{교육·고등교육}→{수치형우세}`.
- → mlxtend FP-Growth + association_rules (support/confidence/**lift**).

### I2. 컬럼 값-도메인 클러스터 = 마스터데이터/중복 탐지
- `column_value_tree` 군집: 최대 **189개 컬럼**이 동일 값 도메인 공유(root 3580). 173·171개 군집도 존재.
- 기관·도메인을 가로지르는 "사실상 같은 컬럼" 집단 → 표준코드/중복/연계 후보.

### I3. 조인키 발견 — combined_pair_map(74만 쌍)의 `linking_ratio`
- 서로 다른 테이블 컬럼 간 값 연결 비율. 고-linking + **도메인 상이** 쌍 = 교차도메인 통합 포인트.

### I4. 테이블 유사도/중복 — table_pair_map(25만 쌍) + table_value_tree(91군집)
- `sim_col_ratio`, `col_val_sim`, `over/eql/inc` 지표로 near-duplicate 데이터셋 탐지(기관 간 중복 공개).

### I5. 서브스페이스 클러스터링 — 컬럼 프로파일 다차원 공간
- distinct_cnt/pk_ratio/rec_cnt/range 등에서 일부 차원에서만 성립하는 컬럼 원형(archetype) 발굴.
